# Supabase — STEP Obras

Use `schema_step_obras.sql` para criar as tabelas, políticas e bucket inicial.

Principais tabelas:

- `step_obras_items`
- `step_obras_photos`
- `step_obras_history`
- `step_obras_config`

Bucket de imagens:

- `step-obras-evidencias`

A chave `service_role` deve ficar somente nas variáveis seguras do ambiente de publicação.
