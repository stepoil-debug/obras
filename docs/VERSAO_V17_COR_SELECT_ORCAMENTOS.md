# Versão v17 — Correção de cor dos campos de seleção

Correção visual aplicada nos campos `<select>` do painel, principalmente no modal **Novo orçamento**.

## Ajuste feito

- As opções abertas dos campos de seleção agora usam fundo branco com texto escuro.
- A opção selecionada permanece destacada.
- O campo fechado continua com o visual escuro do painel.

## Motivo

Em alguns navegadores, o menu nativo do `<select>` abre com fundo branco, mas herdava a cor clara do painel. Isso deixava as opções praticamente invisíveis.
