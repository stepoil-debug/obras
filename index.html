Como usar

Este painel está preparado para publicação online com sincronização no Supabase. Abra o site, clique em Ajustar posições, arraste os números da planta e depois clique em Salvar mapa para gravar as posições no banco. Assim, ao abrir em navegador anônimo ou em outro computador, o mapa carrega as posições salvas no Supabase.

O arquivo principal é o index.html e a sincronização é feita pela rota interna /api/obras.

Próxima evolução recomendada

A versão atual sincroniza os dados com Supabase: leitura da carteira, salvamento das posições do mapa, atualização de obra, envio de imagens pelo telefone e importação de Excel/JSON para atualizar obras e custos. Configure as variáveis de ambiente do site para ativar a sincronização.

Como é uma solução HTML local, imagens muito grandes são comprimidas antes de salvar. Mesmo assim, navegadores têm limite de armazenamento. Para muitos anexos, recomendo migrar o armazenamento das fotos para nuvem.
